Before you start

What you need

  • FreeCAD 1.0 or newer. Free, from freecad.org. On Linux use the official AppImage: the snap, Flatpak and distro packages ship no Python of their own, so with them you can join a team but not start one.
  • One AI helper installed and signed in once. Claude Code (claude), Codex (codex) or OpenCode (opencode). Run it once in a terminal and finish its sign-in. CADSwarm starts it for you after that.
  • A terminal, for one command. PowerShell on Windows, Terminal on macOS and Linux.
  • Teammates are optional. One person and one helper is a working team; everyone else can join later with a code.
What you'll be running

CADSwarm is a FreeCAD workbench plus a small team server. The server runs on one person's computer (the host) next to the model file. Nobody needs a CADSwarm account.

Step 1

Install CADSwarm

Paste one line into a terminal. It fetches CADSwarm, finds FreeCAD, puts the workbench into it, offers a shortcut, and opens FreeCAD.

PowerShell 
> irm https://raw.githubusercontent.com/SachchitBalamurugan/cadswarm/main/install/quick-install.ps1 | iex
Terminal 
$ curl -fsSL https://raw.githubusercontent.com/SachchitBalamurugan/cadswarm/main/install/quick-install.sh | bash
Terminal 
$ curl -fsSL https://raw.githubusercontent.com/SachchitBalamurugan/cadswarm/main/install/quick-install.sh | bash
Linux

Use the official FreeCAD AppImage. If you don't have one, the installer offers to download it (about 3 GB unpacked). With a snap or Flatpak you can join a teammate's team but not start one.

About 70 MB of helper software lands in CADSwarm's app folder — %APPDATA%\CadSwarm on Windows, ~/Library/Application Support/CadSwarm on macOS, ~/.local/share/CadSwarm on Linux. Nothing is installed into FreeCAD itself.

Checkpoint

FreeCAD opens with the CADSwarm setup guide. If it doesn't, pick CADSwarm in FreeCAD's workbench selector, or open the CadSwarm shortcut the installer made.

Prefer to install by hand, or need to update later? That's all in Install and update.

Step 2

Start a team

You're the first person, so you're the host: your computer keeps the team's model, files and database while everyone works.

  1. Choose “Start a new team project”.

    If you've used CADSwarm before, your past projects are listed above it — pick one to reopen instead.

  2. Name the project and yourself.

    The project name becomes the folder and the tab name of the live model. Your name is what teammates and their helpers see (“Sam”, not an email).

  3. Choose where it's saved.

    The default is Documents\CadSwarm\<project name>. Pick another folder if you like: if it already has other things in it, the project gets its own subfolder, so nothing is mixed in or overwritten.

  4. Choose where the database lives.

    On this computer is the default: no account, works offline, teammates join over your network. Maincloud lets teammates join from anywhere and needs a free SpacetimeDB sign-in, which opens in your browser once.

Click Create my team. The first time, this also downloads the team server and SpacetimeDB (about 50 MB, each checked by SHA-256). It happens once per computer.

Checkpoint

A page titled Your team is ready! shows an invite code that starts with cadswarm-2:. That page also starts your AI helper connection next.

Step 3

Share the code

Copy the invite code and send it however you like — chat, email, a sticky note. Each code works once and expires after a day.

One code per teammate. Make more any time from the panel's Tools ▸ AI helpers ▸ Invite a teammate…, or from the guide's invite page. Teammates paste it into CADSwarm's Get started ▸ Join a teammate's project.

Working alone for now?

Skip this step. You can invite people after your first build; their code doesn't depend on what's already in the model.

Step 4

Connect an AI helper

The guide lists the agent CLIs it found on your computer. Pick one — Claude Code, Codex or OpenCode — and give it a name, or keep the suggested one (sam-claude).

CADSwarm writes that helper's own workspace under the project's AI helpers\ folder, connects it to the team, and starts it in the background. There's no window to keep open and nothing to paste.

Sign in once, first

The CLI must already be signed in on this computer: run claude, codex or opencode in a terminal once. Signing in is the only part CADSwarm can't do for you.

Codex only: in Codex, trust the project so its config loads, then type /hooks and trust the CADSwarm hook. Without that, the helper still works but gets its team context later, through tool calls.

Checkpoint

The CADSwarm panel appears on the right. In its Team tab your helper is listed with a green Ready pill. A live-model tab, named after your project, opens with an empty document.

Step 5

Ask for a part

Type in the panel's chat box. Starting a message with @ gives it to an AI helper; typing @ alone lists the names you can use.

Chat 
@sam-claude build a 120 x 80 x 6 mm plate with a 3 mm chamfer on the top edges
and four M3 clearance holes on a 100 x 60 mm grid

Or hand a whole request to the team, and let the team server plan it into parts and start the helpers:

Chat 
@team a phone stand for a 7 mm phone, printed in PLA, that leans back 20 degrees

Plain text without an @ is chat between people — helpers never see it. That's the whole etiquette: @name = task, @team = brief, @all = a note to every helper, no @ = talk to your teammates.

Checkpoint

The helper answers in the chat — first what it's about to do, then what it did. Shapes appear in the live model tab, coloured by owner. Your message shows ⏳ not read yet, then 👀 read, working on it, then ✓ done.

Step 6

Watch and steer

The panel is the team, in one dock:

  • Team — who's here, what each helper is working on, and what each one holds (the parts only it can change).
  • Tasks — open work and whole-team requests with their parts underneath. Start it, I'll do it, Mark done.
  • Activity — what happened, in order: parts added, tasks finished, files saved, clashes found.
  • Sizes — the shared dimensions every part can read from. Change one and dependent parts update.
  • Files — notes, plans, BOMs and scripts the team saved, with history and a copy button.
  • Tools — edit a part yourself, run a check, export, snapshots, library, settings, helpers' logs.

Two habits make the whole thing click:

  1. Correct in a sentence. “Make the holes 4 mm and move them in 5 mm” is a task the helper can carry out; a new chat window is not needed.
  2. Drag nothing by accident. The live model is read-only for you — moving a part in the 3D view without the editor is undone with an explanation. To change a part by hand use Tools ▸ ✎ Edit a part yourself…, which holds the part while you edit and shares the change when you press Save to team.
Your own drawing stays yours

The team model opens as a separate, read-only tab. Refreshes, new parts and reconnects never pull you away from the document you're working in — only the guide's Done, show me the model brings it forward.

Step 7

Save your files

Everything lives in the project folder, in subfolders that grow as the project does:

Project folder
Phone stand/
  model.FCStd          the live model (only the team server writes it)
  files/               notes, BOMs, scripts (history kept)
  exports/             STL and STEP files, never overwritten
  snapshots/           saved versions of the model
  library/             the team's parts shelf
  AI helpers/          each helper's own workspace
  .cadswarm-team/      the team server's data and design memory

To make a printable file: Tools ▸ Save as STL/STEP file…. To keep a version of the model: Tools ▸ Save a snapshot…. Exporting twice is safe — the second file gets a new name.

Checkpoint

Press Open project folder in the same Tools group, and there's your STL in exports/, next to the model and everything the helpers wrote.

If you're joining, not starting

Skip steps 2 and 3. After installing, open CADSwarm and choose Join a teammate's project, paste the invite code they sent you, then connect your own AI helper (step 4) — helpers always run on their owner's computer.

  • You don't download the team server; only the host does.
  • Your sign-in is kept per team, so reopening the project later needs no new code.
  • On a team hosted on someone's computer, you must be on the same network (and so must your helper's connection). Maincloud-hosted teams work from anywhere.

If something goes wrong

What you seeWhat it means and what to do
“Couldn't reach your team's server at …”The host's computer is off, CADSwarm isn't open there, or you're on a different network. Ask the host to open CADSwarm; if you're on a local team, check you're on the same Wi-Fi.
“That project's database isn't on this computer's team server any more”The team was rebuilt from empty (a fresh database). Start it again from CADSwarm ▸ Get started — your model file is still in the project folder, so nothing is lost.
“That project's database is paused on SpacetimeDB”Only for Maincloud teams. Open the database on spacetimedb.com, click Start Database, then reconnect.
“That invite code has already been used or has expired”Codes work once and last a day. Ask for a new one from Tools ▸ AI helpers ▸ Invite a teammate….
The helper never answersOpen Tools ▸ AI helpers ▸ Show my AI helpers' logs. The usual cause is a CLI that isn't signed in yet, or (Codex) an untrusted hook — type /hooks and trust it.
The panel says ReconnectingThe host's team server stopped. It starts again when the host opens CADSwarm; everything else waits for it.
Linux: helpers or team server won't startYou're on a snap, Flatpak or distro FreeCAD. Switch to the official AppImage (the installer can fetch it).

The troubleshooting chapter covers the rest, including disk space, firewalls and what to do when a teammate's helper goes quiet.
